Test 04 – Diáknap 2026: a page that reacts

You make the student day page work with JavaScript: buttons that change text, cards built from data, a sign-up button and a filter.

Conditions

  • Only the offline W3Schools site is allowed. No AI, no internet, no phone.
  • Time: 45 minutes.
  • Graded.

Read this first

  • You get a finished page: index.html, style.css, and script.js with the data in it. Open index.html in the browser. It loads your script.js.
  • You write almost everything in script.js, below the line // Write your code below this line. Feature B also needs one rule in style.css, and Feature D needs a few lines in index.html.
  • Read index.html to find the ids you need. Read the data at the top of script.js to see what a programme looks like. Do not change the data.
  • Every feature is scored on its own. If you get stuck on one, move to the next.
  • A wrong id breaks everything after it. document.getElementById("wrong-id") gives null, and null.addEventListener(...) is a red error in the Console (F12). The lines after it do not run, so the later features stop working too. Keep the Console open, and fix or comment out the broken part before moving on.
  • Partial work scores. Commented-out code does not score.
  • Save before the time is up. Files saved after the end of the test score 0.

FEATURE A — Napszak buttons (8 pts)

The page has three buttons (Reggel, Délben, Este) and a paragraph below them that says Válassz napszakot!

When a button is clicked, the paragraph shows that button’s text:

Button clicked The paragraph shows
Reggel Reggel 9-kor indul a Focikupa a tornateremben.
Délben Délben kosárdobó verseny az udvaron.
Este Este 6-kor diákdisco az aulában.

Done when: each button changes the paragraph to its own text, and clicking them in any order always shows the text of the last one clicked.

FEATURE B — Programme cards (12 pts)

Use a loop to add one card to <div id="cards"> for every programme in programs:

  • The card is an <article> with the class card.
  • Inside it: an <h3> with the programme’s title, and a <p> with its place and time, like Tornaterem, 9:00.
  • The loop must still work if programmes are added to or removed from the array.

Then, in style.css, put the cards next to each other: use flexbox, with a 16px gap, and let the cards wrap into a new row when they don’t fit.

  • Hint: programs is an array of objects. programs[0] is one programme, and programs[0].title is its title. programs.title does not exist.
  • Hint: flexbox goes on the element that holds the cards, not on the cards.

Done when: 6 cards show, the first one is Focikupa / Tornaterem, 9:00, and they sit in two rows: 4 cards in the first row and 2 in the second.

FEATURE C — Sign-up button (10 pts)

The Robotépítő műhely section shows Szabad helyek: ? and a Jelentkezem button. The number of free seats is in the workshop object in script.js.

  1. When the page loads, the ? is replaced with the number of free seats from workshop. Do not type the number.
  2. Every click on Jelentkezem takes one seat: decrease the seats in the workshop object, then show the new number on the page.
  3. When no seats are left, the button text changes to Betelt, the button is disabled, and it gets the class full.
  • Hint: change the object itself (workshop.seats). A new variable or a typed number does not count.

Done when: the page starts with Szabad helyek: 3. After 3 clicks it shows 0, the button says Betelt and is grey, and clicking it again changes nothing (the number never goes below 0).

FEATURE D — Filter by type (10 pts)

  1. In index.html, in the Szűrés típus szerint section, above the empty list, add a <select> with the id type-select and a label Típus: connected to it. The options:

    Option text Value
    Összes all
    Sport the type value of the sport programmes
    Zene the type value of the music programmes
    Játék the type value of the game programmes

  2. In script.js: when the select changes, the list <ul id="results"> shows one <li> with the title of each programme of the chosen type. Összes shows all of them.

  • Hint: a label is connected when its for matches the select’s id.
  • Hint: the option values must match the type values in the data exactly. Copy them from the data.
  • Hint: empty the list first, or the old results stay.

Done when: choosing Zene shows exactly Karaoke and Tanárzenekar, then choosing Sport shows exactly Focikupa and Kosárdobó verseny (nothing from before), and clicking the word Típus: puts the focus on the select.

BONUS — Favourite hearts (+4 pts, not required)

Give every card from Feature B a heart button: <button class="heart">♡</button>.

Clicking a heart toggles the class fav on that heart and changes it to ♥. Clicking it again changes it back to ♡. The other hearts don’t change.

Do it with one click listener on <div id="cards">, not one per heart.

Done when: you can switch any heart on and off on its own, and your code has exactly one addEventListener for the hearts.
