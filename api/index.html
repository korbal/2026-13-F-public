Osztály API

Valódi adatok, valódi URL-ekről, fetch-csel. Csak GET kérést tud.

Alap URL:

https://korbal.github.io/2026-13-F-public/api/

Lépésről lépésre, önellenőrző feladatokkal: 1. Mi az a JSON?.

Bármelyik végpontot megnyithatod a böngészőben is. Mielőtt kódot írsz, nézd meg, milyen alakú az adat.

Végpontok

excuses.json

Kifogások arra az esetre, ha nincs kész a házi. Tömb, minden eleme egy objektum.

{ "id": 3, "excuse": "Nálam működött.", "category": "technika",
  "believability": 6, "teacherHeardIt": true }
excuses/1.json … excuses/16.json

Egyetlen kifogás az id-ja alapján. Objektum. Nem létező id esetén a válasz 404.

canteen.json

A heti menza. Objektum, a napok a days tömbben vannak. Figyelj: a dessert néha null.

{ "week": 46, "school": "Széchenyi", "days": [
  { "day": "hétfő", "soup": "...", "main": { "name": "Rántott sajt rizzsel",
    "vegetarian": true, "calories": 820 }, "dessert": null,
    "queueMinutes": 12, "rating": 4.5 }, ...
] }
cats.json

Macskák. Tömb, és minden macskában van egy hobbies tömb (lehet üres is).

{ "id": 2, "name": "Null", "age": 2, "weightKg": 3.4, "sleepHoursPerDay": 12,
  "friendly": false, "hobbies": ["poharak leverése az asztalról", "hajnali négykor futás"] }
index.json

Az összes végpont listája, JSON-ban.

Így kérsz le adatot

async function loadExcuses() {
  // 1. Elküldjük a kérést, és megvárjuk a választ
  const response = await fetch("https://korbal.github.io/2026-13-F-public/api/excuses.json");

  // 2. A válasz szövegét JavaScript-adattá alakítjuk (ez is időbe telik, ezért await)
  const excuses = await response.json();

  // 3. Innentől ez egy sima tömb, ugyanúgy dolgozol vele, mint eddig
  console.log(excuses);
  console.log(excuses[0].excuse);
}

loadExcuses();

Feladatok

  1. Írd ki a konzolba az összes kifogást, majd csak az első kifogás szövegét.
  2. Jelenítsd meg a kifogásokat egy <ul> listában az oldalon.
  3. Kifogásgenerátor: egy gombra kattintva jelenjen meg egy véletlenszerű kifogás (Math.random()).
  4. Csak azokat a kifogásokat mutasd, amelyeket a tanár még nem hallott (teacherHeardIt), hihetőség szerint csökkenő sorrendben.
  5. Rakd ki a menzát táblázatba: nap, leves, főétel, desszert. Ahol nincs desszert, ott ez álljon: „nincs”.
  6. Melyik napon a legrövidebb a sor? Mennyi az összes kalória a héten?
  7. Készíts kártyát minden macskának, a hobbijaival együtt. Ha nincs hobbija, írd ki: „semmi, csak létezik”.
  8. Számold ki a macskák átlagos alvásidejét, és emeld ki azt, amelyik a legtöbbet alszik.
  9. Egy számmezőbe beírt id alapján kérd le az excuses/<id>.json végpontot. Ha 404 jön vissza, írd ki: „Nincs ilyen kifogás.”
