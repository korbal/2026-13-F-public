# 2026-13-F-public

Public pages for the 13F1 Frontend-Backend class (2026/27): https://korbal.github.io/2026-13-F-public/

`index.html` is the home page, in English: lessons, then tests (oldest first). The class API is not linked from it; lessons link to it where they use it.

`api/` is a read-only JSON API for `fetch` practice (GitHub Pages serves it with `Access-Control-Allow-Origin: *`). `api/index.html` is the docs page with tasks; `api/index.json` lists the endpoints. Lessons live in one folder per series (`dom/`, `fetch/`, `git/`), as `NN-<slug>.html`, and the home page links one page per lesson, top to bottom: DOM, Fetch, Git. Every lesson opens in English; except Fetch 2 (English only for now), `?lang=hu` or the page's Magyarul button switches it to Hungarian (remembered per browser), and `?prep` is the teacher's view: no slides, every task opened with its solution already run, a Show task / Show solution toggle, Prev / Next (Alt+←/→), nothing saved. The two combine: `?prep&lang=hu`. `dom/01-data-to-elements.html` (DOM 1) and `fetch/01-what-is-json.html` (Fetch 1) are in the VS Code practice shape: slides, then eight tasks in a VS Code look-alike with the live page beside it. `fetch/02-data-from-a-server.html` (Fetch 2) is the same shape with five slides and six tasks: `fetch` from the class API with `async`/`await`; inside the practice, `fetch` answers from a copy of `api/` after a short wait (a wrong address gives a 404). Git is the teacher's own trainer, copied in from github.com/korbal/git-practice as `git/git-practice.html` (update it by copying that repo's `index.html` again); its `?prep` shows each lesson solved, with the commands that solve it. Old URLs only redirect: `dom/01-adatbol-elemek.html` to DOM 1, `fetch/01-json.html` to Fetch 1, `git/01-git-egyedul.html` and `git/01-save-points.html` to Git practice. `git/first-push.html` is a reading page, not a trainer: the first push (clone, config, add, commit, push, logout) with why each step is there, English with the same `?lang=hu` switch; it grows with pull, status and log later. `git/home-push.html` is its homework, same reading shape: generic steps with a check after each (`pwd`, `ls`, `git status`), push `rolam.md` from home on any OS (token on Mac/Linux, no OneDrive folder), then find the repo on the H: drive at school, `git pull` and `git log`. `fetch/02-json-utvonalak.html` is an older practice page, not linked, to be reworked into lesson format. The fetch series builds up to querying the API. Test folders never move, so old links keep working.

One folder per test (`testNN/`), linked from `index.html` (oldest first):

- `demo.html` – **Hibák**: the class's most common mistakes, wrong and right side by side (shown on the projector).
- `walkthrough.html` – **Javítás**: fix-it tasks built from the real mistakes; the page checks each fix itself.
- From Test 04: `solution/` – **Megoldás**, the full solution with step-by-step comments, plus `testNN-megoldas.zip`, the paper (`paper.html`) and the starting files (`testNN-kiindulo.zip`) for practising at home.

No student names, grades or feedback go here.
