Git 1 · Git egyedül

Kezdőlap

Ez egy gyakorló terminál: úgy viselkedik, mint az igazi Git, de semmit nem tudsz elrontani. Bal oldalt a projekt fájljai: rájuk kattintva szerkesztheted őket, és látod, mit gondol róluk a Git. Írd a parancsokat a terminálba, Enterrel futnak (a ↑ előhozza az előzőt). Ha kész, nyomd meg az Ellenőrzés gombot.

Most a saját gépeden, az igazi Gittel. Csináld végig a lépéseket a VS Code termináljában, aztán másold be ide, amit a parancsok kiírnak. Az oldal megnézi, rendben van-e.

A lépések

  1. A Webdev mappádban hozz létre egy git-lecke mappát, és nyisd meg VS Code-ban (File → Open Folder).
  2. Nyiss terminált: Terminal → New Terminal. Nézd meg, hogy a sor végén a git-lecke mappa áll-e.
  3. git init. Ha még nem tetted meg ezen a gépen: git config --global user.name "A neved" és git config --global user.email "az@emailed.hu".
  4. Csinálj egy index.html-t (bármi lehet benne), és commitold.
  5. Csinálj egy style.css-t, kösd be az index.html-be, és commitold.
  6. Változtass valamit a style.css-ben, és commitold. Minden commit üzenete mondja meg, mi változott.
  7. Csinálj egy jegyzet.txt-t (a saját jegyzeted, ami nem kell a projektbe), és egy .gitignore-t, amiben a jegyzet.txt szerepel. A .gitignore-t commitold.
