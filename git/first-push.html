Git: first push, step by step

What you do, and why. Back to home

The goal: your own repo on GitHub, with a hello.txt pushed from this computer, and the commit shows your name.

The picture

Your project has two copies:

GitHubonline, others can see it
▲ pushclone ▼
Your computeryou work here: file → add → commit

The copy on GitHub is safe if your computer dies, and others can see it. The copy on your computer is where you work. Git moves changes between the two, but your computer only talks to GitHub when you tell it to (clone, push, later pull). Everything else happens on your computer.

Words

Repository (repo)
A project folder that Git watches. It remembers every saved version.
Commit
One saved version of the project, with a message and the name of who made it.
Remote
The copy on GitHub. Its default name is origin.

The steps, and why

1Is Git there?

git --version

Expected: git version 2.x

Why: it checks that Git is installed and the terminal can find it. If this fails, nothing else will work, so it comes first.

2Log in to GitHub

At github.com, with your own account.

3Create a repo

Top right + → New repository. Name: elso-repo, Public, tick Add a README file, then Create repository.

Why: the repo starts on GitHub. The README puts one file in it, so it isn't empty and you can download it straight away.

4Copy your repo's link

On your repo's page: green Code button → HTTPS → copy icon.

Why: this link is your repo's address. You copy it instead of typing it, because one typo means Repository not found.

5Go to the Desktop

cd ~\Desktop

Why: cd means "change directory": it moves the terminal into a folder. Whatever you do next happens in that folder.

6Download your repo

Type git clone , paste your link, press Enter. Then:

cd elso-repo

Why: clone downloads the whole repo from GitHub into a new folder, and remembers where it came from. That is why git push later knows where to send things. cd elso-repo steps into that folder: git commands only work inside a repo.

7Tell Git who you are

Your own name, and the email you used for GitHub:

git config user.name "Your Name"
git config user.email "your-github-email"

Why: every commit carries a name and an email. GitHub uses the email to link the commit to your account and your picture. A wrong email means your work shows up as someone else's, or as no one's. Without --global it is set for this repo only, which is what you want on a shared school computer.

8Make a file and push it

echo hello > hello.txt
git add .
git commit -m "first commit"
git push

A login window opens. Log in with your own GitHub account.

Why, line by line:

echo hello > hello.txt
Creates a file. Git sees it but does not save it yet.
git add .
Chooses what goes into the next save. The . means "everything in this folder".
git commit -m "first commit"
Saves a version on your computer, with a message saying what changed. GitHub doesn't know about it yet.
git push
Sends your commits to GitHub. This is the first time GitHub needs to know who you are, so the login window opens.

Why three steps instead of one "save"? add lets you choose what goes in, commit makes it a version you can go back to, and push shares it. Later you will make many commits and push them all at once.

9Check on GitHub

Refresh your repo's page: hello.txt is there, and the commit shows your name.

Why: the commit only counts if GitHub shows it. Your name and picture on it prove that steps 7 and 8 worked.

10Log out before you leave the computer

Start menu → Credential Manager → Windows Credentials → git:https://github.com → Remove. Then log out of github.com in the browser.

Why: Windows remembers your GitHub login on this computer. If you don't remove it, the next person who pushes from this machine pushes as you, into your account.

If it breaks

Read the error message. All of it.

'git' is not recognized
No Git, or the terminal can't find it. Tell the teacher.
not a git repository
You're not inside the repo folder: cd elso-repo
Please tell me who you are
You skipped step 7. Do it, then commit again.
Repository not found
Typo in the link. Copy it again from the green Code button.
403 / Permission denied
Someone else's login is still saved on this computer. Remove it (step 10) and push again.

Coming later

  • git pull: download changes others made, from GitHub to your computer.
  • git status and git log: see what changed and who did what.
