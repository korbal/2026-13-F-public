Git homework: push at home, pull at school

The follow-up to the first push. Back to home

In class you pushed from the school computer to GitHub. Now, at home, you add a file to the same repo from your own computer and push it. In the next Git class you pull it down on the school computer, and it is there.

The two computers never talk to each other. Both talk to GitHub. This is how your team will work on the vizsgaremek.

Before you start

  • Your GitHub login (username and password), and your phone in case GitHub asks for a code.
  • Your elso-repo repo from class. If you didn't get one in class, create it now: First push, step 3.
  • A computer you are allowed to install on. If it is your parents', you may need their password once, for the install.

Which computer do you have?

Pick one. The page then shows only the steps for your computer.

At home

No problem. GitHub lends you a computer in the cloud that you use in the browser. It works on a phone in theory, but it is painful: borrow a computer or use a library one if you can.

Open a codespace

On github.com, open your repo. Green Code button → Codespaces tab → Create codespace on main. Wait a minute or two. A VS Code opens in your browser with a terminal at the bottom. No terminal? Top left ☰ → Terminal → New Terminal.

Why: a codespace is a computer in GitHub's cloud. Git is already installed, your repo is already downloaded and you are already logged in. You skip the install, token and clone steps.

Open a terminal

Start menu → type powershell → Enter.

Cmd + Space → type terminal → Enter.

Ctrl + Alt + T, or find the app called “Terminal”.

Is Git there?

git --version

If you see git version 2.x, you already have Git: skip the next step.

On a Mac a window may pop up instead, offering to install the “command line developer tools”. That is the next step.

Install Git (only if step 2 failed)

winget install --id Git.Git -e --source winget

If it asks something, type Y and Enter. If Windows asks for permission (“Do you want to allow…”), click Yes. When it is done, close PowerShell and open a new one, then again: git --version

If it says winget is not recognized: download the installer from git-scm.com/downloads/win (Click here to download), run it, click Next on every screen, then Install. The defaults are fine.

In the pop-up: Install → Agree. It can take 5–15 minutes. If no window came up, type:

xcode-select --install

When it is done, again: git --version

Ubuntu, Mint, Debian:

sudo apt update
sudo apt install -y git

Fedora:

sudo dnf install -y git

sudo asks for the computer's password. Nothing shows while you type: that is normal, type it and press Enter.

Why: on the school computer someone installed Git for you. At home that is your job. You do it once and the computer keeps it.

Make a token

Open github.com/settings/tokens/new (log in if it asks).

  • Note: homework
  • Expiration: 30 days
  • Tick the top box: repo
  • At the bottom: Generate token. Copy it (it starts with ghp_) and keep the tab open: GitHub shows it only once.

Why: on Windows, the push opens a login in the browser. On Mac and Linux the terminal asks for a username and password, and GitHub does not accept your normal password there. A token is a password just for Git. If someone gets it, you delete it, and your GitHub password stays safe.

Go to your home folder

cd ~

Why: ~ is your user's own folder, on every computer. We don't use the Desktop: on many home Windows computers the Desktop syncs to OneDrive, and OneDrive fights with Git. Same problem as the drive at school.

Download your repo

On your repo's page: green Code button → HTTPS → copy icon. Type git clone , paste your link, press Enter. Then:

cd elso-repo
ls

There is the hello.txt you made at school.

Why: this is the first proof. You made that file on a different computer, and now it is here, because it came through GitHub.

Tell Git who you are

git config user.name "Your Name"
git config user.email "your-github-email"

Why: this is a new computer (or a new folder), and it doesn't know what you set at school. Same name and email as in class, so GitHub knows this is you too.

Write rolam.md

notepad rolam.md

It asks whether to create the file: Yes. Write your name and your favourite song or game. Ctrl + S, then close Notepad.

nano rolam.md

Write your name and your favourite song or game. Save: Ctrl + O, then Enter. Quit: Ctrl + X. (Ctrl on a Mac too, not Cmd.)

code rolam.md

It opens in the editor above. Write your name and your favourite song or game, then Ctrl + S.

Save it and push

git status

You see rolam.md in red under Untracked files: Git sees it but isn't saving it yet.

git add .
git status

Now it is green under Changes to be committed: it goes into the next commit.

git commit -m "rolam from home"
git push

A window pops up: Sign in with your browser → in the browser, Authorize. With your own account.

The terminal asks. Username: your GitHub username, Enter. Password: paste the token (not your password!), Enter. Nothing shows when you paste: that is normal.

On Linux it asks again on every push. That is fine for now.

No login: you are already logged in inside the codespace.

Check on GitHub

Refresh your repo's page. rolam.md is there. Click the commit count (clock icon, top right above the file list): you see the school first commit and the home rolam from home, both with your name.

This is the proof of the homework. It is what the teacher checks.

Delete the codespace

Go to github.com/codespaces → ⋯ next to your codespace → Delete.

Why: the free hours per month are limited. Your work is on GitHub, so the codespace isn't needed any more.

Shared family computer? If others use it, remove your login like at school. Windows: Start → Credential Manager → Windows Credentials → git:https://github.com → Remove. Mac: Keychain Access → search github.com → right-click → Delete. Your own computer: no need.

At school (next Git class)

The school computers run Windows, so this part is the same for everyone.

Go to your folder from last time

Open PowerShell. Wherever you cloned last time:

cd ~\Desktop\elso-repo

or, if you put it in C:\temp:

cd C:\temp\elso-repo

Cannot find path? The folder is gone (different computer, or it was wiped). No problem: clone again (First push, steps 5–6) and jump to step 3. The fresh clone already has rolam.md, because GitHub has it.

Pull

git pull

You see something like Fast-forward and rolam.md | 1 +.

Why: pull is the opposite of push. It asks GitHub whether there are new commits, and if there are, downloads them to this computer. No login needed: your repo is public, so anyone can read it.

Look

ls
cat rolam.md
git log

The file you wrote at home is here. git log shows every commit: who made it and when. If you see : or (END) at the bottom, press q.

Why: find in the log which commit was made at school and which at home. Same name, two computers, and GitHub joined them up.

Log out

The pull didn't log in, so there is nothing to remove. If a login window did pop up, do First push step 10 before you leave the computer.

If it breaks

Read the error message. All of it.

'git' is not recognized / command not found: git
You didn't open a new terminal after installing. Close it, open a new one. Still there? The install didn't work: redo step 3.
'winget' is not recognized
Older Windows. Use the downloadable installer (step 3, second paragraph).
xcrun: error: invalid active developer path
Mac without the developer tools: xcode-select --install
destination path 'elso-repo' already exists
You already downloaded it once. cd elso-repo, then git pull, and carry on.
Password authentication is not supported / Authentication failed
You typed your GitHub password instead of the token. Push again and paste the token as the password.
GH007: Your push would publish a private email address
Your email is hidden on GitHub. Copy the …@users.noreply.github.com address from github.com/settings/emails, then: 
git config user.email "the-noreply-address"
git commit --amend --reset-author --no-edit
git push
403 / Permission denied to someone-else
Someone else's GitHub login is saved on this computer (a brother, sister or parent). Remove it (see “Shared family computer”) and push again.
Repository not found
Typo in the link. Copy it again from the green Code button.
At school, git pull gives a strange error (local changes, divergent branches)
Don't fight it. Get a fresh copy from GitHub into a new folder: 
cd ..
git clone your-repo-link elso-repo-2
cd elso-repo-2
GitHub shows the commit without your name or picture
Your user.email doesn't match your GitHub account's email. Fix it; the next commit will be right.

If nothing helps: send the teacher a screenshot of the whole error message.
