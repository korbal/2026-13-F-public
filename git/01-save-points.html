A practice terminal. It answers like real Git, and you cannot break anything here. Your project's files are on the left: click one to edit it and to see what Git thinks of it. Type commands in the terminal and press Enter (↑ brings back the last one). When you are done, press Check.

Now on your own machine, with real Git. Do the steps in the VS Code terminal, then paste what the commands print. The page checks it.

The steps

  1. In your Webdev folder, make a folder called git-lesson and open it in VS Code (File → Open Folder).
  2. Open a terminal: Terminal → New Terminal. Check that the prompt ends in git-lesson.
  3. git init. If Git asks who you are, or you have never done it on this machine: git config --global user.name "Your Name" and git config --global user.email "you@example.com".
  4. Make an index.html (anything in it) and save it in a commit.
  5. Make a style.css, link it from index.html, and commit.
  6. Change something in style.css and commit. Every message says what changed.
  7. Make a notes.txt (your own notes, not part of the project) and a .gitignore with notes.txt in it. Commit the .gitignore.
  8. Break the page on purpose: in style.css give the body font-size: 6em;. Look at it in the browser. Commit it anyway.
  9. Load the last good save: find that commit in git log --oneline and run git revert --no-edit <hash>. Check the browser again.
